# Modelos entrenados

Guarda aquí cada exportación de la sección 12 del cuaderno en una subcarpeta con un nombre que identifique la versión. Incluye juntos `eco_web.json` y `eco_web_pesos.bin`.

Para publicar una versión nueva, copia ambos archivos a la carpeta `../modelo/`, reemplazando los anteriores, y sube los cambios a la rama `main`. Render desplegará el modelo actualizado automáticamente.
