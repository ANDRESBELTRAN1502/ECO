# ECO
ECO · Identificador Visual de Residuos es una red neuronal convolucional (CNN) que reconoce un residuo a partir de una foto o de la cámara , según el código de colores de Colombia (Resolución 2184 de 2019). La red se entrenó desde cero con 15.493 imágenes del dataset Garbage Classification de Kaggle y distingue 12 tipos de residuo.
